# ❄️ 寒霜刺客幫工具 - 領主裝備與寶石升級計算機 (雲端同步版)

專為寒霜啟示錄 (Whiteout Survival) 刺客幫盟友設計的專業計算與雲端存檔工具。支援跨裝置雲端進度儲存、管理者白名單授權控制、琥珀自動折算設計圖紙等強大功能。

---

## 🌟 核心功能特色

1. **👤 盟友雲端存檔中心 (白名單機制)**：
   - 玩家只需輸入自己的 **遊戲 ID**，一鍵載入之前儲存的 6 部位裝備階級、寶石等級與背包庫存數量。
   - **管理者權限控管**：只有在管理者白名單內的遊戲 ID 才能使用雲端儲存/覆寫功能，未授權者依然可作為一般計算機使用。
2. **🔄 琥珀自動折算設計圖紙 (NEW)**：
   - 依據 **1 個月光琥珀 = 10 張設計圖紙** 的兌換比例。
   - 勾選「**啟用琥珀自動折算為設計圖紙**」後，系統會將目標階級所需之琥珀需求量 × 10 直接合併至設計圖紙，琥珀需求自動歸零，差額與進度條即時連動計算！
3. **🛡️ 領主裝備計算**：包含普通到神話T6全星級子階（強韌合金、拋光液、設計圖紙、月光琥珀）。
4. **💎 領主寶石計算**：包含 1 寶到 18 寶全階段（寶石手冊、寶石圖紙、寶石秘典/水晶）。
5. **📦 背包庫存差額**：輸入現有庫存數量，自動算出還差多少，即時顯示百分比與進度條。
6. **🚀 戰力與屬性提升**：自動預算升級獲得的屬性加成（%）、實力提升與出征容量增加。
7. **🎽 雙模式自由切換**：支援「快速件數乘數試算 (1~6 件)」與「6 部件個別勾選自訂起點/目標」。

## ☁️ 雲端 0 元 24H 永不休眠架構 (與 wos_redeemer 相同)

本系統與 `wos_redeemer` 採用相同之雲端高效架構：

1. **Web 服務器**：Python Flask + Gunicorn (附 `Procfile` 與 `requirements.txt`)，可直接部屬至 **Render / Railway / Koyeb** 等免費雲端平台。
2. **資料庫 (永久保存)**：
   - 本地端自動使用 SQLite (`chief.db`)。
   - 雲端環境設定 `DATABASE_URL` 環境變數即可自動無縫切換至 **Supabase 免費 PostgreSQL 資料庫**，重啟伺服器資料絕不遺失。
3. **24H 永不休眠**：
   - 系統內建 `/api/ping` 端點。
   - 於 **UptimeRobot** 或 **cron-job.org** 設定每 5~10 分鐘定時 GET 請求 `https://你的網址/api/ping`，即可讓免費雲端伺服器**永久處於喚醒狀態，全年無休 ($0 免費)**。

## ⚙️ 管理者後台操作說明

- **預設管理密碼**：`alina5085` (可由環境變數 `ADMIN_PASS` 自訂)
- **進入後台**：點擊網頁頂部的 **「⚙️ 管理者設定」**，輸入密碼即可進入。
- **後台功能**：
  1. **新增白名單**：輸入要開通存檔權限的遊戲 ID、角色名稱與備註。
  2. **白名單列表**：查看已授權成員清單、是否已建立雲端存檔與最後更新時間。
  3. **移除授權**：一鍵刪除不再允許存檔的 ID。
