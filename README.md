# ❄️ 寒霜刺客幫工具 - 領主裝備與寶石升級計算機

專為寒霜啟示錄 (Whiteout Survival) 玩家設計的獨立計算工具。

---

## 🌟 功能特色
1. **🛡️ 領主裝備計算**：包含普通到傳說T6全星級子階（合金、拋光液、圖紙、月之琥珀）。
2. **💎 領主寶石計算**：包含1寶到11寶全階段（寶石手冊、寶石圖紙、升級水晶）。
3. **📦 背包庫存差額**：輸入現有庫存數量，自動算出還差多少，即時顯示進度條並自動儲存。
4. **🚀 戰力與屬性提升**：自動預算升級獲得的屬性加成（%）、實力提升與出征容量增加。
5. **🎽 雙模式支援**：支援「快速倍數試算」與「6 部件/6 寶石個別設定」。
6. **📱 跨平台免安裝**：既可透過 Python 本地執行，亦可直接雙擊 `index.html` 在瀏覽器開啟使用。

---

## 🚀 使用與分享方式

### 方式 A：雙擊直接開啟（免安裝環境，最推薦分享給朋友）
直接雙擊點開 **`index.html`**，即可在 Chrome、Edge、Safari 或手機瀏覽器中直接使用！

### 方式 B：一鍵啟動本地 Web 服務
雙擊 **`start.bat`**，系統會自動在瀏覽器開啟 `http://127.0.0.1:5050`。
